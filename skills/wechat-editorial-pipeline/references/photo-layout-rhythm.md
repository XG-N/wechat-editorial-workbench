# 照片组合与正文节奏

适用于照片逐张堆放显得单调，或参考图中有大小组合、图文并排和主题点缀的文章。先决定照片在正文里说明什么，再选择版式；不要先套模板，再搬动内容凑形状。

## 先排图位，再选组合

把稿件按语义段落列出，每张图标明角色：引景、现场动作、对象细节、证据对照或视觉收束。核对照片主体、方向、清晰度和出处是否支持这个位置。信息应能从文字走到图片，再回到下一段；不能把配图全调到开头，使后面的重点章节只剩文字。

节奏来自不同信息关系，不是给每张图都换花样。可在宽图、同题双图、照片配短句之间选两三种；短文或资料不足时，清楚的单图比勉强拼组更合适。某节只有必要文字可以保留，不设“每章必须配图”或固定照片数量。

| 关系 | 适合怎样使用 | 何时回退 |
| --- | --- | --- |
| 宽图引景或收束 | 场景主体较多，需要看清环境；沿正文阅读边线展开 | 低分辨率或纵图不强拉成横幅，改居中单图 |
| 同章节双图 | 同一观察的两个细节、前后状态或不同视角；原图比例相近 | 不同章节、比例悬殊或一张缩小后主体不可辨，拆回原段落 |
| 照片配已有短引文 | 图像与一句原文共同表达停顿、观察或结论 | 没有合适短句时不编标语；文字在手机上碎成窄长列时恢复上下结构 |
| 局部细节承接 | 文字刚提到的对象在图中能够看见，随后仍有相关正文 | 不用无关素材填空，不把图库写成真实活动现场 |

## 当前可复用配置

`campus-warm` 的 `editorial-rhythm` 继承连续阅读版的窄纹理与奶油到白色内沿。以下是散步示例的准确配置片段，其他稿件需换成实际登记ID和已有引文：

```json
{
  "layout": "campus-warm",
  "body_layout": "editorial-rhythm",
  "photo_pairs": [],
  "photo_duos": [
    ["sunlit-urban-steps-20261022", "sidewalk-shadows-20261022"]
  ],
  "quote_photo": {
    "id": "park-bench",
    "quote": "散步可以没有一个值得汇报的结果。"
  },
  "body_ornaments": {"intro": "walk-intro", "quote": "ginkgo-mark"}
}
```

源稿先把两张同题照片写成相邻的独立图片段落，不能隔着正文或章名。构建会核对相邻关系和接近的纵横比，再组成52:48双图，右列下移16px，组下合并编号图注。它不负责从全文搜图拼到一起；构建拒绝时先检查图位与素材关系，不靠删除正文通过。

引文配图须在Markdown中紧跟唯一的已有引用块，不能隔着一段文章。当前实现为左48%摄影、右52%原句，右列可加38px透明点缀，整体垂直居中。组合之后仍接源稿原本的后续段落。52:48、16px和38px是此预设的实现值，不是所有题材的固定设计准则。

## 点缀应有依附对象

正文导入的小景连接封面与阅读区；引文旁的叶片呼应照片内容与停顿。小装饰靠近图组、短句或章节转折，正常文档流排列，不单独留一大块空地。先看缩到手机宽度后是否仍能辨认，再决定保留。

生成装饰登记 `generated-decoration`、`decoration_only`、实际工具、生成身份和SHA，透明PNG保留alpha；不计入真实摄影数量。摄影继续保留作者、源页、许可、原下载件与使用件SHA。参考的机构标识、仪式象征、署名及二维码不能跟随版式迁入。

## 实际复核与反馈回写

查看整篇和局部，而不只检查图片数量：主体缩小后能否辨认；两图视觉重量是否接近；图注是否压图、悬空或失去对应；短句是否挤成碎行；点缀是否抢过照片；边框与文字间是否有稳定阅读面。核对正文、章名、引用和摄影出处没有因组合而遗漏或重复。

以手机宽度先检查组合，再看较宽版；保留用户反馈前后的文件身份。Pillow校样只证明文档合成结果，不能称为浏览器、微信公众号清洗或手机实测。“无重叠”也不等于排版合适。无账号时交付本地预览并保留未验状态，不自动上传或发布。

后续文章复用的是“信息角色—图位—组合—看图修正”的判断。若用户反馈失衡，只调整受影响组合；不要在全篇单图和全篇拼图之间来回切换。联网学习须实际打开原页面，区分看到示例图与只读到文字；具体取舍和来源另记在项目 `research/references/20261022-online-photo-layout-study.md`，不将模板展示当作免费商用授权。
