# 城市文旅推文流程

先确定文章用途和读者，再根据下列材料与结构制作。没有的事实保留缺口，不用模板补造。

## 最少需要的事实

- 真实地点、交通方式和游览范围
- 开放时间、预约、费用的核对日期；时效信息注明来源
- 当地照片对应的拍摄地点与图注，不从库存图片推断路线体验

## 两种可用结构

- 一个地方细节 → 路线 → 沿途观察 → 实用信息 → 适合怎样的读者
- 半日主题 → 两至四个地点 → 时间安排 → 交通与休息点 → 行前核对

## 写作与去模板化

- 用街道、声音、材料或动作描述地方，避免人间仙境等万能形容
- 没有到访经历时采用资料整理语气，不写我走过、亲测
- 价格、营业状态和路线时长允许未知；测算与实走分开

## 真实照片检索

- 地点全名 + 官方旅游 摄影
- Wikimedia Commons + place name photograph
- Unsplash + city exact landmark photograph

源页与许可逐张核对；下载原图并看图。图库是氛围，不能冒充活动现场、产品客户或到访记录。

## 版式配方

照片承担地点辨认，路线信息紧邻对应照片；暖色窄边、小标题与简短实用清单。

动态主标题用完整首帧、缓慢局部装饰、主题背景与静态备份；正文不依赖网页动画。

## 专项审核

- 国外图库照片不得冒充本地景点
- 路程、票价和开闭馆状态须当前核对
- 拍摄季节与文章日期不作无依据对应

再完成通用五项语义复核：事实、自然文风、首轮校对、最终校对和照片。指纹变化后重新核对。

## 可直接使用的制作指令

请围绕【主题】制作一篇面向【读者】的城市文旅公众号文章。先核实材料和文章状态，选择本手册中适合的结构；缺少关键事实时只暂停依赖部分。正文自然具体，不编经历、引语、数字或效果；用真实且有使用依据的摄影配图。制作主标题GIF、适配背景和紧凑排版，做双轮全文校对与来源审核，交付预览、审核报告和可追溯文件包。
