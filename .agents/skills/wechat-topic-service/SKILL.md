# 公益服务推文流程

先确定文章用途和读者，再根据下列材料与结构制作。没有的事实保留缺口，不用模板补造。

## 最少需要的事实

- 服务的对象、资格、时段、地点、费用与提供方
- 可核实的官方联系方式和申请步骤
- 活动成效的数据来源、统计口径及是否模拟

## 两种可用结构

- 读者遇到的问题 → 可获得的帮助 → 适用对象 → 办理步骤 → 常见问题 → 官方入口
- 一个真实服务场景 → 工作过程 → 经核对的变化 → 下一次服务安排

## 写作与去模板化

- 先让读者知道能得到什么帮助，再介绍组织
- 不用弱者叙事制造感动，不编受助者故事或感谢语
- 资格、补贴和办理条件沿用官方准确措辞

## 真实照片检索

- 服务机构官网 + 活动名称 + 摄影
- 用户授权的服务现场原图
- Wikimedia Commons community garden photograph（仅氛围）

源页与许可逐张核对；下载原图并看图。图库是氛围，不能冒充活动现场、产品客户或到访记录。

## 版式配方

办理步骤与联系方式易找；图注区分真实现场和公开氛围图，避免大量宣传口号与空白。

动态主标题用完整首帧、缓慢局部装饰、主题背景与静态备份；正文不依赖网页动画。

## 专项审核

- 资格、费用、服务日期与联系方式逐项核对
- 不泄露受助者身份与健康信息
- 模拟成果与真实服务效果不可混写

再完成通用五项语义复核：事实、自然文风、首轮校对、最终校对和照片。指纹变化后重新核对。

## 可直接使用的制作指令

请围绕【主题】制作一篇面向【读者】的公益服务公众号文章。先核实材料和文章状态，选择本手册中适合的结构；缺少关键事实时只暂停依赖部分。正文自然具体，不编经历、引语、数字或效果；用真实且有使用依据的摄影配图。制作主标题GIF、适配背景和紧凑排版，做双轮全文校对与来源审核，交付预览、审核报告和可追溯文件包。
