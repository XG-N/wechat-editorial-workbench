# 微信草稿交付

没有公众号账号时，仍可完成写作、配图、动态标题、排版、审核与本地导出；不能保存到官方草稿箱或称为后台验收通过。注册与登录由用户本人完成，不推断账号身份。

本项目2026-10-22的后续授权是将示例存入公众号草稿、实际检查并修复，暂时不发布；用户随后明确当前没有微信公众号账号。因此本次停在完整本地成品与无外发草稿计划，后台验收待账号开通。账号状态变化后以当次核对为准。

## 已登录Edge路径

1. 确认浏览器控制工具能可靠识别当前公众号网址与账号。工具安全校验停止时，停止该浏览器操作；用户授权不能修复工具的网址识别故障。
2. 打开 `build/preview.html`，复制排版正文到新文章；填元数据中的标题、摘要与用户提供的真实署名。
3. 正文照片和动态标题逐个使用微信上传入口上传并替换；本地路径、data URL、外链图在本地预览可见，不代表微信已获得图片。
4. 保存草稿后确认标题、照片数量顺序、图注、背景、动效与封面。需要手机预览时按本次授权操作；没有真实手机确认则记录未验证。

不在该路径自动安装扩展、开调试端口、修改安全设置或操作认证对话框。

## API路径

`draft <目录>` 是无外发的本地计划。`draft <目录> --upload` 才会实际上传，读取 `WECHAT_APP_ID` 与 `WECHAT_APP_SECRET`；运行前明确写入目标账号草稿在用户授权内。凭据不落盘、不写入交付包。

实现顺序：审核当前指纹 → 获取token → 上传正文图片 → 上传封面 → 新增草稿 → 保存media_id回执。普通JPEG/PNG走正文上传接口；GIF走永久图片素材接口。每次上传保留进度，接口返回与客户端显示分开核验。

官方参考：

- [新增草稿](https://developers.weixin.qq.com/doc/offiaccount/Draft_Box/Add_draft.html)
- [永久素材](https://developers.weixin.qq.com/doc/offiaccount/Asset_Management/Adding_Permanent_Assets.html)

本轮官方页面抓取失败，参数实现另对照固定版本 `JimLiu/baoyu-skills` 源码；不能声称已实时通读官方文档。实际账号首次调用仍要核对权限、IP白名单、GIF保留和客户端效果。

接口错误时输出错误码而不输出含密钥的请求URL。新增草稿结果未知时，先检查后台再恢复，不自动重复。图片素材上传与草稿是不同写入步骤，草稿失败不表示素材未产生。已有相同指纹回执时拒绝重复创建。

此工具没有公开发布或群发接口。用户明确要求发布时，再依据当次账号、最终文章和权限执行对应动作。
