# 八类主题制作手册

按当前题材只读取对应章节。各配方是制作建议，真实材料和用户要求优先。

## 共用的图文决策

需要组合变化时先读[照片组合与正文节奏](photo-layout-rhythm.md)，再按当前题材判断照片承担的作用。下表是选择依据，不是每篇必须采用的固定模板或照片数量。

| 题材 | 可采用的内容关系 | 不能因版式改变的事实 |
| --- | --- | --- |
| 校园活动 | 现场全景引景、同一环节的动作与细节成组、已记录原话配人物/活动摄影 | 时间、人物与原话必须真实；图库不冒充学校现场 |
| 科技科普 | 真实设备/材料全貌与同一对象细节并列，原理解释留清楚阅读面 | 不把摄影当实验结果；关键结论仍有研究依据 |
| 城市文旅 | 路线场景宽图、同处环境与局部细节成组，短观察配图 | 不同地点或时点不能拼成到访记录 |
| 项目产品 | 实物/使用场景与细节对照，已核实的功能说明与摄影并列 | 摄影不代替功能、性能或客户证据，不编体验引语 |
| 生活随笔 | 宽图引景、同一观察的两个细节、已有短句配图 | 不为了图文配合虚构作者经历，图库明确为氛围 |
| 公益服务 | 办理环境与服务对象所需物件细节，说明文字紧随实际步骤 | 不拍脑袋补条件、联系方式或真实受益效果 |
| 热点解读 | 按已核时间线排列摄影，同一事件不同视角可局部成组 | 旧图、新图与不同事件的图不能误构成前后对照 |
| 读书文化 | 书籍实拍、版本细节与已有评论短句配合 | 封面和内页不代替版本/页码核对，不编作者原话 |

若相邻图片不属于同一信息关系、比例不合或主体缩小后难辨，保留单图；没有合适短句时不用引文配图。点缀使用与主题相符且身份清楚的插画，不能替代事实性摄影。

## campus · 校园活动

### 校园活动推文流程

先确定文章用途和读者，再根据下列材料与结构制作。没有的事实保留缺口，不用模板补造。

## 最少需要的事实

- 活动正式名称、主办方、日期、地点与活动性质
- 预告或回顾的状态；报名方式、截止时间与适用对象
- 人数、奖项、发言与照片须有原始记录；未核实项标为缺口

## 两种可用结构

- 预告：读者为什么要来 → 时间地点 → 活动看点 → 报名方式与限制 → 行前提醒
- 回顾：一个已核实的现场细节 → 活动过程与代表片段 → 真实产出 → 后续入口

## 写作与去模板化

- 把活动信息写全；开头避免盛大举行、圆满落幕等无信息口号
- 有采访材料再写人物声音；没有原话不编引语或掌声
- 区分报名人数、到场人数与参与人次；日期、星期与校区逐项核对

## 真实照片检索

- 活动全名 + 主办方 + 现场 原图
- 学校官网 + 活动名称 + 摄影
- Unsplash university campus students photography（仅氛围图）

源页与许可逐张核对；下载原图并看图。图库是氛围，不能冒充活动现场、产品客户或到访记录。

## 版式配方

清晰日期信息条、按过程组织的真实照片、短图注与明确报名入口；正文16px，间隔12—26px。

动态主标题用完整首帧、缓慢局部装饰、主题背景与静态备份；正文不依赖网页动画。

## 专项审核

- 不能把图库学生照片当作本校现场
- 核实肖像使用依据、未成年人照片范围
- 奖项、姓名、职务和报名截止时间逐字核对

再完成通用五项语义复核：事实、自然文风、首轮校对、最终校对和照片。指纹变化后重新核对。

## 可直接使用的制作指令

请围绕【主题】制作一篇面向【读者】的校园活动公众号文章。先核实材料和文章状态，选择本手册中适合的结构；缺少关键事实时只暂停依赖部分。正文自然具体，不编经历、引语、数字或效果；用真实且有使用依据的摄影配图。制作主标题GIF、适配背景和紧凑排版，做双轮全文校对与来源审核，交付预览、审核报告和可追溯文件包。

## 交付与下一步

正文Markdown、元数据、事实台账、照片清单、动态/静态标题、微信正文片段、预览、审核报告与SHA清单。实际后台草稿和手机效果必须分别核验，不能从本地通过推断。


## science · 科技科普

### 科技科普推文流程

先确定文章用途和读者，再根据下列材料与结构制作。没有的事实保留缺口，不用模板补造。

## 最少需要的事实

- 明确一个问题与读者已有知识，列出术语定义
- 论文、官方文档或原始数据的链接、日期与适用条件
- 数字的单位、分母、比较基线及不确定性

## 两种可用结构

- 问题 → 直观例子 → 原理 → 能做什么 → 不能据此得出什么 → 来源
- 一个常见误解 → 证据 → 机制 → 应用条件 → 实用判断

## 写作与去模板化

- 比喻之后回到准确术语，明确比喻的边界
- 不把相关性写成因果，不把实验室条件写成现实普遍结论
- 保留版本、样本量、研究对象与是否同行评审；不编造专家和实验

## 真实照片检索

- 技术或设备精确型号 + manufacturer media press photos
- 论文机构官网 + 实验装置 photography
- Wikimedia Commons + 实物名称 + photograph

源页与许可逐张核对；下载原图并看图。图库是氛围，不能冒充活动现场、产品客户或到访记录。

## 版式配方

## 专项审核

- 证据是否真的支持正文主张
- 新旧模型与软件版本是否混用
- 健康、法律、金融相关结论另按高准确性来源核实

再完成通用五项语义复核：事实、自然文风、首轮校对、最终校对和照片。指纹变化后重新核对。

## 两种可用结构

- 一个地方细节 → 路线 → 沿途观察 → 实用信息 → 适合怎样的读者

- 第一人称经历须由用户提供；没有经历可写观察、建议或明确虚构
- 引用、数据和健康结论有来源；不为生活感编造人物经历

- 一个可见的细节 → 一个生活问题 → 两三种具体做法 → 留一个可执行的动作

## news · 热点解读

### 热点解读推文流程

先确定文章用途和读者，再根据下列材料与结构制作。没有的事实保留缺口，不用模板补造。

## 最少需要的事实

- 事件发生时间、首次发布和最新更新时间
- 官方原始材料与至少可区分立场的信源
- 已证实事实、当事人表述、推断与未知的界线

## 两种可用结构

- 发生了什么 → 已确认的事实 → 关键背景 → 各方表述 → 对读者的影响 → 仍待确认
- 一个具体疑问 → 时间线 → 证据比较 → 有限结论 → 后续观察点

## 写作与去模板化

- 事件日期与报道日期分开写，标题不把可能写成定论
- 引用必须对应原文，未经证实的传播不当作证据
- 表达观点时说明依据，不制造情绪对立或补造内幕

## 真实照片检索

- 事件主办方 官方发布现场摄影
- 当事机构 press release photo credit
- Wikimedia Commons exact event date photograph

源页与许可逐张核对；下载原图并看图。图库是氛围，不能冒充活动现场、产品客户或到访记录。

## 版式配方

顶部注明资料截至时间；事实、分析与时间线清晰分组；每张新闻图标明时间地点和来源。

动态主标题用完整首帧、缓慢局部装饰、主题背景与静态备份；正文不依赖网页动画。

## 专项审核

- 标题是否超过证据强度
- 旧图是否被当作新事件现场
- 争议表述是否正确归因，是否遗漏后续更正

再完成通用五项语义复核：事实、自然文风、首轮校对、最终校对和照片。指纹变化后重新核对。

## 可直接使用的制作指令

请围绕【主题】制作一篇面向【读者】的热点解读公众号文章。先核实材料和文章状态，选择本手册中适合的结构；缺少关键事实时只暂停依赖部分。正文自然具体，不编经历、引语、数字或效果；用真实且有使用依据的摄影配图。制作主标题GIF、适配背景和紧凑排版，做双轮全文校对与来源审核，交付预览、审核报告和可追溯文件包。

## 交付与下一步

正文Markdown、元数据、事实台账、照片清单、动态/静态标题、微信正文片段、预览、审核报告与SHA清单。实际后台草稿和手机效果必须分别核验，不能从本地通过推断。


## reading · 读书文化

### 读书文化推文流程

先确定文章用途和读者，再根据下列材料与结构制作。没有的事实保留缺口，不用模板补造。

## 最少需要的事实

- 作品名、作者、译者、版本和引用页码
- 读者的问题或评论角度
- 引文与转述区分；书影和场馆照片的使用依据

## 两种可用结构

- 一个阅读问题 → 一段短引文 → 具体分析 → 与另一观点对照 → 适合怎样的读者
- 作品背景 → 一个细节或人物 → 个人判断 → 局限 → 阅读建议

## 写作与去模板化

- 围绕文本细节展开，不用全网必读、改变一生替代评论
- 没有读完或没有原文时说明依据范围，不编页码与引语
- 引用短而必要；自己的分析比摘抄更充分

## 真实照片检索

- 作者或出版社 官方书影 press kit
- 用户授权的实体书照片
- Unsplash library reading photograph（仅氛围）

源页与许可逐张核对；下载原图并看图。图库是氛围，不能冒充活动现场、产品客户或到访记录。

## 版式配方

书名、版本和引文层级明确；温暖背景和适量照片；不以巨幅留白制造所谓书卷感。

动态主标题用完整首帧、缓慢局部装饰、主题背景与静态备份；正文不依赖网页动画。

## 专项审核

- 引用、译本和页码是否对应
- 书影是否有使用依据
- 作者观点与文章作者观点是否清楚区分

再完成通用五项语义复核：事实、自然文风、首轮校对、最终校对和照片。指纹变化后重新核对。
